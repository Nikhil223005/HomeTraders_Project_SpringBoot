# Homesteader React Landing Page

## Run in VS Code
1. Install Node.js LTS.
2. Extract this ZIP and open the `Homesteader_React_Landing_Page` folder in VS Code.
3. Open Terminal in that folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL printed by Vite.

## Included
- Responsive React landing page
- Navigation and mobile menu
- Crop category filtering and search
- Searchable illustrative market prices
- Enquiry form modal and validation
- Sign-in modal placeholder
- Newsletter form demo
- Crop imagery from Unsplash

## Important
This is a frontend demo. Price values are illustrative, and forms do not save data yet. Connect forms and authentication to your Spring Boot REST APIs and MySQL database before production use.
